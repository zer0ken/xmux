# Braille X atlas source

The two HTML files are the source for the checked-in binary atlas. xmux reads the atlas at runtime and does not launch a browser.

To regenerate it, install the pinned Playwright dependency in this directory, install its Chromium browser, then run `node scripts/generate_braille_x.cjs` from the repository root. The HTML selects Arial, Georgia, and Segoe UI Symbol. Browser and font differences can change generated bytes. The Rust tests verify every front-frame fingerprint and reject isolated unlit dots.
