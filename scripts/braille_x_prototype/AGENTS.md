# Working Notes: /scripts/braille_x_prototype

## Purpose

The HTML source of the Braille X animation atlas.

## Module Seams

- Two HTML files, one per frame size, and the pinned Playwright dependency the generator
  one level up uses to render them.

## Invariants

- xmux reads only the generated atlas at runtime and never launches a browser.
- Browser and font differences change the generated bytes, so the atlas is regenerated
  only with the pinned dependency.
